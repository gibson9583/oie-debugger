# OIE Debugger 1.0.1

- Debugging is disabled by default. Idle observation reuses scope observers and avoids repeated source-registry locking when enabled.
- Long sessions no longer stop accepting commands after 256 operations. Commands use increasing sequence numbers and bounded receipts so retries do not execute an expired command again.
- Source listings, source details, and the channel picker respect the user's channel access. Access refreshes cannot restore stale channel choices or arm a revoked target.
- Debugger audit events preserve source and channel targets without recording expressions or request bodies.

Requires OIE 4.6.0, Java 17 or newer, Web Administrator plugin API 4.7 or newer, and the Web Support extension.

Install the signed ZIP through the engine's extension installer, restart the engine, and reload Web Administrator before arming a session. Explicitly saved `enabled=true` settings remain enabled after upgrading. For a new installation, set `enabled=true` in the JavaScript Debugger extension properties and redeploy target channels. Disable debugging when finished.

Both plugin JARs are signed with SSL.com eSigner. Verify the complete ZIP against the release's `SHA256SUMS` file.
